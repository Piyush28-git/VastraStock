# Security Policy

## Scope

VastraStock is an early local-first browser prototype. It stores information in browser local storage and does not currently provide authentication, encryption at rest, server-side storage, or multi-user permissions.

## Responsible disclosure

Please do not publish exploitable security issues as public issues. Contact the maintainer privately through the GitHub profile to coordinate a report.

## User guidance

- Do not enter sensitive personal, customer, supplier, banking, or tax information.
- Use the JSON export to back up test data.
- Do not treat this prototype as an accounting, invoicing, or statutory tax system.
